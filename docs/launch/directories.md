**AlternativeTo description:** VOLUMA is a free, open source macOS app that reads and writes NTFS, exFAT and FAT drives and browses ext4, APFS and HFS+. It writes to NTFS with its own driver (no kernel extension), copies between drives, shows where disk space went, and installs with `pip install nolo-voluma`.
